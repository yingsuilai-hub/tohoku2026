奧入瀨溪流 JR BUS 慢旅行

本章採用「青森站 → 子之口下車 → 沿溪流緩下坡步行 → 奧入瀨溪流館搭 JR BUS 返回青森」的長輩友善路線。重點是：不用走完全程，可依體力在途中巴士站撤退。

👴 長輩友善
🚌 JR BUS 官方路線
⬇️ 由上游往下游緩下坡
🚏 可中途撤退
🚶 推薦 2–3 小時精華散步

本章結論

最佳走法

子之口 → 銚子大瀑布 → 雲井之流／雲井之瀑 → 石戶 → 奧入瀨溪流館。這是順著溪流方向的緩下坡，比從燒山往子之口走更省力。

最適合你們的版本

Plan A：子之口走到石戶或奧入瀨溪流館。長輩若累了，可在子之口、銚子大瀑布、雲井之流、雲井之瀑、石戶等站直接搭回程巴士。

官方班次重點

JR 巴士東北官方頁面列出青森、新青森、八戶往奧入瀨與十和田湖的停靠站與時刻表；青森始發「湖」號停靠子口、銚子大瀑布、雲井之流、石戶、奧入瀨溪流館等站。

Plan A｜完整長輩版

子之口 → 奧入瀨溪流館
約 6–7 km，含拍照與休息約 3 小時。體力佳、天氣涼爽時採用。

Plan B｜最推薦

子之口 → 石戶
約 4–5 km。景色完整度高，石戶可休息並搭回程巴士。

Plan C｜保守版

子之口 → 雲井之瀑
約 2–3 km。看完核心瀑布與溪流後直接搭回程巴士。

Plan D｜雨天／疲累版

只在子之口、銚子大瀑布、石戶下車拍照
以 JR BUS 為主，步行控制在 1,500–2,500 步。

重要提醒：奧入瀨沿線手機訊號、餐飲補給不一定穩定。請每人攜帶水、簡單點心、雨具、防蚊用品；長輩務必穿防滑鞋。不要把「走到溪流館」當成硬性任務，當天以體力與天氣為準。
